# CLAUDE.md

## Conventional Commits (Strictly Enforced)

You MUST use Conventional Commits format for all commit messages:

**Types:**
- `feat:` new functionality
- `fix:` bug fix
- `perf:` performance improvement
- `refactor:` code restructuring without behavior change
- `test:` adding or improving tests
- `build:` build system or external dependencies
- `ci:` CI/CD configuration
- `docs:` documentation only
- `revert:` reverting a previous commit
- `chore:` miscellaneous (avoid for code paths; prefer explicit types)

**Format:** `type(scope): concise description`

**Examples:**
- `feat(players): add /league-players/{id}/seasons weekly logs API`
- `fix(rosters): prevent swap across locked week; return ErrRosterLocked`
- `perf(sql): replace seq scan with partial index on (league_id, status) where status='ACTIVE'`
- `refactor(service): split LeagueRoster service into add/drop/swap units`
- `test(repository): add fixtures + integration test for waiver bids`

**CRITICAL COMMIT & GIT RULES (ABSOLUTELY NON-NEGOTIABLE):**

**Commit Structure:**
- ALWAYS commit in logical chunks: group files by coherent units of change (e.g., all repository files together, all service files together, migrations separate from application code)
- NEVER create monolithic commits mixing unrelated changes
- Split commits by architectural layer or feature component

**Commit Authorship & Attribution:**
- NEVER EVER co-author commits as Claude, Anthropic, or any AI entity
- NEVER EVER add "Co-Authored-By: Claude" or any similar attribution
- NEVER EVER mention Claude, Anthropic, AI, or "generated by" anywhere in commit messages (title or body)
- NEVER EVER add emojis like 🤖 or footers indicating AI involvement
- Run ALL commits exclusively in the user's name
- Keep commit messages clean, professional, and human-authored in tone
